Connections

Tokens you paste here are checked with the service first, then saved on the server. They're never shown again, never go into GitHub, and can't be downloaded from the website.

📸 Instagram (homepage feed)

…
How to get a new token
  1. Cut off the old one first. In the Instagram app: Settings → Apps and websites → remove your website's app. That kills every token it ever issued, including the one that was public.
  2. Go to developers.facebook.com/apps → your app → Instagram → API setup with Instagram login.
  3. Under Generate access tokens, add or reconnect @energy.best.ca and click Generate token. Log in when asked.
  4. Copy the token and paste it below. It lasts 60 days and the site renews it by itself.

📇 Zoho CRM (leads, install map)

…
How to get a new connection
  1. Go to api-console.zoho.com and open the client the website already uses (its Client ID is the one in config.php — usually Self Client).
  2. Open the Generate Code tab. Scope: ZohoCRM.modules.ALL,ZohoCRM.coql.READ · Time: 10 minutes · Description: website → Create.
  3. Copy the code and paste it below within 10 minutes. Each code works once.
  4. The old token that was public can't be used without your client secret (which never leaked), but once this one works you can remove older authorizations under Zoho Accounts → Connected Apps.

💳 Stripe (payments → Zoho)

…
How to turn on the webhook
  1. In Stripe → Developers → Webhooks click Add endpoint.
  2. Endpoint URL: https://yourenergybest.com/stripe-webhook.php
  3. Events: checkout.session.completed, checkout.session.async_payment_succeeded, invoice.paid, invoice.payment_failed, customer.subscription.deleted → Add endpoint.
  4. On the endpoint page, Reveal the signing secret (starts with whsec_) and paste it below.
  5. Back in Stripe, Send test event → it should show a 200.

How to connect
  1. In Google Cloud, enable Places API (New).

  3. Find your Place ID with Google's Place ID Finder (search your business name).
